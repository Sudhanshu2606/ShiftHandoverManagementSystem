# IOCL Panipat Refinery - Shift Handover Management System

## 📌 Project Overview

A web application that digitalizes shift handover process at IOCL Panipat Refinery.

## 🛠️ Tech Stack

- **Backend:** C# ASP.NET Core (.NET 8) + SQLite + Entity Framework
- **Frontend:** React.js + Bootstrap + Tailwind CSS
- **Authentication:** JWT Tokens

## 🚀 How to Run

### Backend (Visual Studio)

1. Open `backend/ShiftHandoverAPI.sln`
2. Press F5
3. Swagger: `https://localhost:7210/swagger`

### Frontend (VS Code)

1. cd frontend
2. npm install
3. npm start
4. Browser: `http://localhost:3000`
